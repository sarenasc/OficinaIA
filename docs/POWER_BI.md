# Power BI

Automatización visual de Power BI Desktop fuera de alcance inicial, según requisitos. Un agente configurable puede redactar DAX, Power Query, SQL o documentación utilizando su modelo y escribir texto mediante filesystem.write, siempre con permisos explícitos.

No existe conector Power BI, publicación a Service ni ejecución/validación de DAX contra modelos semánticos en esta versión. No se presentan como funciones terminadas. Integración futura por APIs o conectores tipados, con credenciales en vault y auditoría.
